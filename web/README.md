# SpendWise Web

Next.js web dashboard for SpendWise.

## Scripts

```bash
npm run dev      # local development
npm run build    # production build
npm run start    # run production server
npm run lint     # eslint
```

From the repo root you can also run `npm run dev`.

## Environment

Copy `.env.example` to `.env.local` and add your Firebase web app config.

## Vercel

When connecting this repo to Vercel, set **Root Directory** to `web`.
